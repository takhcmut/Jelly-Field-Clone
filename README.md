# Jelly Field Clone

## Requirements
- Unity `6000.3.22f1`

## Run the Game
1. Open the project in Unity Hub.
2. Open `Assets/Scenes/SampleScene.unity`.
3. Press **Play** to start the game.
4. Drag a jelly into an empty cell to play.

Mouse input is supported in the Unity Editor, and touch input is supported on Android.

## Android Build
1. Install **Android Build Support** through Unity Hub.
2. In Unity, open **File → Build Profiles**.
3. Select **Android** and switch to that platform.
4. Add `Assets/Scenes/SampleScene.unity` to the build scenes.
5. Click **Build** or **Build And Run**.
